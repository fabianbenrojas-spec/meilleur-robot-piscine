# /reprise — reprendre une session

Exécuter dans cet ordre, sans rien sauter :

1. Lire `CLAUDE.md`.
2. `npm run preflight` — inventaire des mécanismes canoniques. Ne jamais
   créer un type, composant ou système sans avoir vu cet inventaire.
3. `git log --oneline -15` et `git branch -a` — où en est le travail.
4. Lire les 40 dernières lignes de `DECISIONS.md`.
5. Lire `tasks/` s'il contient un fichier actif.
6. Résumer en cinq lignes maximum : où on en est, ce qui est en cours, ce
   qui bloque. Puis attendre.

Ne rien produire avant l'étape 6.
